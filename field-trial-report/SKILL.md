# 作物品种区域试验总结报告 生成规范（多作物通用）

## 任务说明

本技能把作物品种区域试验（区试）与生产试验的原始数据，整理、撰写成符合区域试验总结惯例的正式报告。报告文体、章节结构、表格形式、术语与评价标准，均以用户提供的往年范本为格式准绳；范本缺失时，按本技能内置的通用结构与作物规范执行。

## 支持作物与作物规范文件

| 作物 | 规范文件（相对本技能目录） |
|---|---|
| 棉花 | `crops/cotton.md` |
| 水稻 | `crops/rice.md` |
| 玉米 | `crops/corn.md` |
| 小麦 | `crops/wheat.md` |

**第一步必做：识别作物。** 从用户数据或要求中判断作物（棉花/水稻/玉米/小麦），然后读取对应的 `crops/<作物>.md`，以其指标、单位、抗性分级与审定标准为准。作物不明确时先向用户确认。扩展新作物：在 `crops/` 下新增 `<作物>.md` 并仿照既有文件填写，再在本表登记一行。

## 通用报告结构（各作物一致的四大部分）

1. **区域试验总结报告**
2. **生产试验总结报告**
3. **抗病虫（病/虫害）性鉴定结果**
4. **品种审定标准**

### 区域试验总结报告 章节顺序

1. **一、试验目的** —— 一句话：鉴定新品种的丰产性、适应性、抗性、品质，为品种审定和大面积生产应用提供科学依据。
2. **二、供试品种（组合）来源及承担单位** —— 供试品种及来源、供种单位、参试年份（表格）；承担试验、抗性鉴定、品质检测单位。
3. **三、试验设计和试验执行概况** —— 试验设计（随机区组排列、重复次数、小区规格）、栽培管理（播期/移栽、密度、施肥、田间管理）。
4. **四、试验期间的气候概况** —— 按试点分别描述各生育时期的气温、降雨、日照及其对生长发育和产量的影响。
5. **五、试验结果** —— 先交代数据纳入情况（对照产量、误差变异系数、纳入汇总试点数），再分「丰产性 / 产量构成因素 / 品质 / 抗性」叙述。
6. **六、品种筛选标准** —— 列出审定/筛选门槛（以 `crops/<作物>.md` 为准）。
7. **七、品种评述** —— 按结论分三类逐一评述：
   - 完成两年区试、进入生产试验的品种；
   - 通过一年区试、续试的品种；
   - 终止试验的品种。
   - 每个品种评述段落固定包含：各试点平均农艺性状 → 产量（亩产、比对照增减产%、位次、显著性）→ 当年抗性鉴定结果 → 当年品质结果 → 形态/特征描述 → 综合结论与建议。

### 生产试验总结报告 章节顺序

一、试验地点及参试品种；二、试验设计；三、试验实施情况；四、试验期间气候特点；五、试验结果及品种评述（含按试点分列的产量数据表）。

### 抗病虫（病/虫害）性鉴定结果 结构

- **材料和方法**：参试品种及对照、菌种/虫源、鉴定方法。
- **鉴定方法**：按病害/虫害分项（病圃/网室、播种移栽、重复、接种与调查方法）。
- **抗性型划分方法**：病情指数/相对病情指数/被害减退率等计算公式与评价标准表。

## 通用表格规范

- 数据表按出现顺序编号（表1、表2、……），标题如「表1 2022年各品种主要数据简表」。
- 常用表格：各品种主要数据简表、各试点产量汇总表、产量构成因素表、抗性鉴定结果表、品质检测结果表、各品种按试点产量明细表。
- 产量、百分比保留一位小数；比对照增减产用「±」表示；位次用「第N位」。
- 对照品种标注「（CK）」，增减产 0.0%、比例为 100.0%。

## 通用语言与文风规范

- 规范农业科技中文，客观陈述，不用口语、不用第一人称抒情。
- 品种名、亲本组合/来源、单位名按原文保留，不擅自改写或缩写。
- 数字与单位之间空一格（如「92.21 kg/亩」）。
- 显著性结论只能依据原始数据或给定统计结果转述，不得自行推断方差分析结论。

## 生成工作流程

1. **识别作物** → 读取对应 `crops/<作物>.md`。
2. **读取输入数据**：参试年份、参试品种清单与对照、各试点数据、抗性鉴定与品质检测结果。
3. **读取范本**（如有）：对齐章节顺序与措辞。
4. **归纳品种**：为每个品种汇总各试点平均的农艺性状、产量、抗性、品质数据。
5. **计算与排序**：计算比对照增减产幅度、产量位次，按筛选标准对品种分档（进生产试验 / 续试 / 终止）。
6. **撰写正文**：按「通用报告结构」顺序成文，先正文后数据表。
7. **生成数据表**：按「通用表格规范」编号与格式。
8. **输出**：默认 Markdown；用户要求 Word（.docx）时用 python-docx 生成并保留三线表风格；要求 Excel 时用 openpyxl 输出数据表。

## 参考范本（可选，格式准绳）

若工作区或本技能 `examples/` 目录下存在往年总结报告（PDF 或已提取的 `.txt`），写作前先读取并对齐其章节结构、措辞与表格样式。范本与用户要求冲突时，以用户明确要求为准。
