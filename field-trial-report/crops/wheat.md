# 小麦（Triticum aestivum）品种区域试验 作物规范

## 关键农艺性状与单位

| 指标 | 单位 |
|---|---|
| 生育期 | 天 |
| 株高 | cm |
| 亩穗数 | 万/亩 |
| 穗粒数 | 粒 |
| 千粒重 | g |
| 容重 | g/L |
| 成穗率 | % |

## 产量指标

亩产（kg/亩）、比对照增减产（%，一位小数）、产量位次、显著性（增产/减产显著或极显著、与对照差异不显著）。对照品种标注「（CK）」，增减产 0.0%、比例 100.0%。

## 品质指标（按强筋/中筋/弱筋分类）

蛋白质含量（%）、湿面筋含量（%）、沉降值（mL）、面团稳定时间（min）、吸水率（%）、拉伸面积、降落数值。

## 抗性指标与分级

- **病害**：条锈病、叶锈病、白粉病、赤霉病、纹枯病——反应型/病级或发病率。
- **抗逆性**：抗寒性、抗倒伏（倒伏率 %）。
- 抗性分级通用：高抗(HR)/抗(R)/中抗(MR)/中感(MS)/感(S)/高感(HS)；条锈病常用免疫/近免疫/高抗/中抗/中感/高感。

## 审定/筛选标准（以当年/当地省级标准为准）

- 产量较对照增产达到显著水平（具体门槛按当地省级审定标准）。
- 品质按用途（强筋/中筋/弱筋/专用）达到相应国家标准或审定要求（如蛋白质、湿面筋、稳定时间门槛）。
- 主要病害达中抗或抗以上，抗逆性达到要求。
